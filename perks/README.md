# Perk images

Photos shown on member perks live here. To add one:

1. Commit the image into this folder, e.g. `perks/popcorn.jpg`.
2. In the **Perks** tab of SciFiDojo_Sheet_v2, set that perk's `image_url`
   to the matching root-relative path: `/perks/popcorn.jpg`.

Keep files reasonably small (long edge ~1200px, ideally under ~300KB) so the
member app stays fast. JPG or PNG. Leave `image_url` blank for a text-only perk.
