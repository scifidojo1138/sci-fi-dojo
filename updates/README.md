# Weekly Rewind images

Photos shown on Weekly Rewind posts live here. To add one:

1. Commit the image into this folder, e.g. `updates/new-arrivals.jpg`.
2. In the **Updates** tab of SciFiDojo_Sheet_v2, set that post's `image_url`
   to the matching root-relative path: `/updates/new-arrivals.jpg`.

Keep files reasonably small (long edge ~1200px, ideally under ~300KB) so the
app stays fast. JPG or PNG. Leave `image_url` blank for a text-only post.
