# Event images

Photos shown on member events live here. To add one:

1. Commit the image into this folder, e.g. `events/movie-night.jpg`.
2. In the **Events** tab of SciFiDojo_Sheet_v2, set that event's `image_url`
   to the matching root-relative path: `/events/movie-night.jpg`.

The image appears inside the event card when a member taps to expand it.
Keep files reasonably small (long edge ~1200px, ideally under ~300KB) so the
member app stays fast. JPG or PNG. Leave `image_url` blank for a text-only event.
